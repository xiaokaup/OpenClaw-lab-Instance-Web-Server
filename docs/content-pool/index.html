人不会为公司哭，只为被当人对待
情感共鸣 · ENFJ · 质量8.9 · active
许昌，胖东来附近。

一个老板在镜头前红了眼眶，
反复说：舍不得。

很多人不理解：
一家超市而已，至于吗？

但我想说——
人，从来不会为一家公司哭。🏪

人会哭，
是因为在某个地方，
第一次被当成「一个人」对待。

不是「消费者」，
不是「业绩」，
是「你」。

你买到的每样东西，
都有人替你把关；
你提的每个意见，
都有人认真听完。

这种「被认真对待」的感觉，
在这个把人当流量的时代，
太稀缺了。💧

所以那个老板哭的，
不是一家店，
是被好好对待过的自己。

愿我们都能遇到，
把你当「人」看的那个地方、那个人。
