匹配链（策略的核心语义）

一条策略 = 一条匹配链，每环指向同一个未满足需求：
📡 信号蛋饼店主卖爆单→ 🎯 需求被看见/被确认→ 👤 人设ENFJ→ 📄 母题暖意→ 🎨 方式社会证明→ 📡 渠道小红书→ 📦 产品人格报告
母题≠钩子（母题=叙事内核·讲什么；钩子=表达技巧·怎么抓注意力）
